# Financial planning candidate

Local compatible addition to the public planning seam. No frozen mathematical modules or existing default limits are changed. The candidate is not published.

`@neural-charts/core/financial` exposes `planFinancialChart`,56 family identifiers, parameter descriptors and readonly OHLCV types. `@neural-charts/core/cartesian` exposes the shared Cartesian planner without retaining radial/graph families. General `planChart` dispatches to both owners; public frame schema remains nc-plan/1 with optional financial metadata, multipart paths and directional/hollow bars.

Data uses unique source/point IDs, strictly increasing numeric/time X, valid open/high/low/close ranges and optional nonnegative volume. A gap has all four OHLC values null; it is never a zero candle. Volume-dependent calculations reject missing volume. Original values stay in observations/consumer tables. Derived Renko/Point-and-Figure IDs retain their source identity; multiple boxes/columns are actual price transformations, not another Line alias.

Parameters are explicitly described by financialParameterKeys. Irrelevant/unknown parameters are rejected. Periods are bounded1–4096. Defaults are14 except Bollinger/CCI/DPO/Keltner/price envelopes20, AO5/34, Klinger34/55 with13 signal, MACD/APO/PPO12/26, Ichimoku9/26/52, pivot blocks14. PSAR uses acceleration.02 capped.2. Renko/Point-and-Figure accept positive boxSize; P&F reverses only after reversal boxes (default3). A default box uses one twentieth of the source price range, bounded away from zero. Geometry generation has a finite derived-point budget.

Moving averages reset their warmup at missing data. EMA/Wilder seed with a simple average. Bollinger uses sample deviation. RSI is50 for flat data,100 for no losses and0 for no gains. Flat Stochastic/Williams use neutral50/−50. Undefined zero-denominator rates remain missing; SVG never receives NaN/Infinity. VWAP is cumulative unless an explicit rolling period is provided. Linear regression uses actual X, normalized by an explicit xUnit or the smallest positive X interval. Trendline fits all available points while preserving gaps. Ichimoku uses actual future source coordinates where available, otherwise the final observed interval for displacement. Pivot levels use only the preceding complete block. Volume profile bins original volume by typical price and preserves original source data separately.

Calculations are independent implementations of the documented mathematical definitions, not imported Highcharts runtime/code. Inventory reference: https://www.highcharts.com/docs/stock/technical-indicator-series and the dated official API type inventory. Renderer ownership remains unchanged: measurement, labels, styles, input/gestures and DOM/resources belong to adapters.

Validation: tests/plan/financial.mjs exercises all56 families on source/zero/gapped data (168 planning cases), immutable source, finite geometry, public dispatch, original candle metadata, known moving-average/deviation/regression/RSI vectors and invalid OHLC. Full existing Core unit/property/plan tests pass in the isolated candidate. Further financial browser/visual/large-data gates belong to the consuming adapters and must not be inferred from these pure tests.
